模型与分析设置

本地模型或你选择的兼容服务。配置会用于之后添加的任务，队列中已有任务保持原配置。

首次使用 / 无法连接？
  1. 从 ollama.com/download 安装并启动 Ollama。
  2. 在 ollama.com/search 选择支持图片输入（Vision）的本地模型，复制其下载命令到终端运行：ollama pull 模型名:标签。等待下载完成。
  3. 点击「自动连接并保存」。也可「刷新列表」选择模型后保存。初次尚未配置时，APP 每 20 秒自动重试。

自动选择最近安装或更新的本地视觉模型；这不代表能力排名。保存后保持你的选择。升级模型后刷新列表即可，无须升级帧脉。软件不附带或自动下载模型。

自定义端口 / 检测失败：切到「手动配置」，地址填 http://127.0.0.1:11434/api（修改为实际端口），模型名复制 ollama list 的完整名称，开启 AI 后保存。普通本地 Ollama 无需密钥。

密钥仅保留在本次程序会话中，不写入配置文件。关键帧会发送到你填写的服务。
FRAMEPULSE MEDIA / 0.1

影像记录，属于你的工作流。

每个素材对应一个开放 JSON 记录。其他应用可以定位素材、跳转镜头、读取画面区域，并保留每个判断的来源。

01 / IDENTITY

认出同一个素材

SHA-256 内容标识与源文件位置分离。移动或重命名素材，不改变它的身份。

02 / ADDRESSING

定位到时间与画面

微秒时间区间采用前闭后开；区域坐标按图像宽高归一化，并锚定具体关键帧。

03 / PROVENANCE

让每个判断可追溯

区分测量、AI 推断和人工编辑，保留证据帧、运行来源、确认状态与修改历史。未知值留空。

一个素材，一个可携带的记录包

<素材 SHA-256>/
  record.fmp.json    完整影像记录
  frames/            关键帧与画面证据

导出支持完整 JSON、镜头 CSV 与 W3C Web Annotation。时间、区域和来源语义保持一致。

为 FlowDesk 和其他应用提供 CLI

framepulse analyze "D:\Media\film.mp4"
framepulse validate "record.fmp.json"
framepulse serve

发现可用的本地视觉模型时自动接入；使用 --no-vision 可只做测量。远程模型需要明确配置。
