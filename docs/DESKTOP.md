# 桌面版使用

FramePulse 0.2.1 提供独立 Windows 窗口、任务栏图标、原生文件选择器与拖拽导入。打包版内置 Python 分析后台和 FFmpeg，使用者无需安装 Python、Node.js 或启动浏览器。AI 模型服务独立配置，不随安装包附带权重。

当前 GitHub Release 提供源码 ZIP；下载后按 README 安装 Python / Node 并双击 Setup、Start，即可打开本桌面 APP。下面的「打包版」描述适用于自己构建的独立包。模型接入见 [Ollama 指南](OLLAMA.md)。

## 导入与队列

1. 将视频、图片或整个文件夹拖进窗口；也可使用「选择文件 / 选择文件夹」。目录递归扫描，支持中文、空格路径，重复的待处理路径自动跳过。原媒体只读。
2. 在「模型设置」选模型，在导入时选择模式和是否 AI 分析，加入队列后检查列表。
3. 点击「开始队列」。同一时间只派发一份素材，避免多任务争用显存；每镜完成即保存恢复记录。
4. 「暂停」会让当前素材继续完成，再暂停后续任务。「取消」停止当前/待处理任务；取消或失败的任务可重试，复用已完成镜头。
5. 关闭 APP 会暂停队列、停止当前任务并等待断点保存。下次打开时保留任务，点击开始/恢复后继续；不会在启动时偷偷派发任务。远程凭证需要重新输入。

当前每次最多加入 10000 份媒体，支持单张图片和最长 45 分钟的视频。45 分钟是单份视频的输入边界，不是处理时限承诺。长片耗时受编码、分辨率、镜头数和模型影响；详见性能记录。

## 预览与标注

播放器提供播放/暂停、镜头跳转、静音、音量、播放速度与全屏。视频没有音轨时不能产生声音；声音播放不等于音频内容识别。

点击画面下方的主体标签，会暂停并定位到该标注的证据帧，高亮轮廓框与名称；「显示标记」可控制显隐。区域只对应特定关键帧，播放时不把静态框假装成对象追踪。整片概括显示媒介类型、主题、标签和分析覆盖范围；尚未分析的部分不会被当作已知内容。

## 文件位置与退出

- 已打包 APP 默认把库放在用户的 FramePulse 应用数据目录。
- 本项目的 `Start-FramePulse.cmd` 指定项目 `runtime/library`，继续使用已有分析结果。
- `FramePulse.exe --data <绝对路径>` 可指定其他库；移动程序前先保留该库。
- 配置和队列保存在库根目录的 `settings.local.json`、`queue.local.json`；每份素材记录在 SHA-256 子目录。
- 每个桌面实例只管理自己创建的后台进程，不会关闭已有 FlowDesk、Ollama 或其他本地服务。

源码开发模式需要 Python 3.10+ 与 Node.js 22.12+，首次运行 `Setup-FramePulse.cmd`，后续运行 `Start-FramePulse.cmd`。构建独立版本使用 `scripts/build-desktop.ps1`；构建在无 system-site-packages 的隔离环境完成。安装/免安装目录也提供 `framepulse.cmd`，FlowDesk 可直接调用，无需另装 Python。
