# 0.2.0 本地验收记录

验证日期：2026-09-22，Windows x64。当前版为独立 Electron APP + 冻结分析后台；以下记录区分模型实际调用、界面操作、自动化与发布状态。

## 自动化与构建

- Python：**72 passed**；仅两项依赖弃用提示。包含真实 FFmpeg 生成媒体、VFR/PTS、图片 EXIF、45 分钟输入边界、档位指纹、顺序提帧、取消恢复、JSONL 检查点、整片概括与人工保护。
- JavaScript：**24 passed**，其中界面 18 项、桌面生命周期 6 项。覆盖声音、倍速、区域证据定位、概括摘要、原生 drop 文件路径桥接、模型/会话密钥、队列控制、存储故障、同源原生 IPC、退出时等待检查点。
- 真实队列单元测试包含中文路径文件夹递归、重复路径、重启恢复、取消/重试，以及磁盘故障发生在派发前、终态保存时和恢复时的情况。已完成且无待处理任务时仍可重试终态落盘，不能因内存显示完成而丢失磁盘记录。

## 真实模型与性能

新增并校验官方 `qwen3.5:4b-q4_K_M`，原有 9B 摘要与官方一致。模型选择依据与来源见 [MODELS.md](MODELS.md)。完整时间及条件见 [PERFORMANCE.md](PERFORMANCE.md)。

- 14.93 秒三维短片：4B 与 9B 均完成 6 镜；首次 4B 187.223 秒，复用测量后的 4B 38.602 秒、9B 48.698 秒。它们不是同一冷启动条件。
- 4 分 37 秒 AV1/4K 真人 MV：4B 完整分析 112 镜、336 张证据、220 个区域建议，1012.073 秒，0 失败。
- 34 分 24 秒 H.264/4K 动画：完整测量 1031 个候选段、2850 张证据，384.379 秒；没有执行完整逐镜 AI。
- 原配置恢复短片：1.301 秒，包装实际 provider 方法计数为 **0 次模型调用**。
- 单张真实 JPEG（从测试视频取出的画面）：9B 分析 6.298 秒，1 次模型调用，1 画面、0 失败；图片无伪造视频时长。

上述记录均通过 JSON Schema 与时间/引用校验。模型完成和协议校验不证明语义准确：实际观察到 4B 错猜角色姓名与不准的区域，9B 在对应描述中不再猜该姓名，但仍未建立整体准确率真值。

## 可见 APP 与交付

已实际打开独立 FramePulse 窗口，检查短片播放时画面/时间前进、静音状态切换、跨镜跳转、区域标签暂停并定位对应证据帧、模型设置中发现并选择 4B/9B、批量队列工作区，以及 Windows 原生文件夹选择器显示。主体框高对比显示，标签明确标注 AI 推断；概括折叠栏显示媒介与主题。

最终 0.2.0 构建再次通过真实窗口验收：在 APP 中填写中文文件夹路径，扫描出两张图片并保持待处理；点击窗口关闭，后台退出且任务仍在磁盘；重开后恢复为 paused + 2 pending，不自动调用模型；点击「恢复队列」后两项完成。第一张已有人工描述，0.2 秒内跳过 AI 并保留人工值；第二张实际用 9B/均衡完成，约 10.9 秒。界面和落盘状态一致。

冻结后端在仅 Windows PATH、空 PYTHONPATH 下完成中文视频 3 镜/9 帧测量，CLI 在 TEMP 工作目录可运行且正确返回退出码。最终 Electron smoke 无渲染错误，原生桥接有效，contextIsolation/sandbox 开启、nodeIntegration 关闭。NSIS/ZIP 完整性和 SHA-256 已核对，ZIP 含 CLI、后端和许可证。

自动化 drop 测试不能写成已验证了资源管理器跨窗口真实拖放；安装器构建成功不能写成另一台全新电脑已安装成功。

本地交付独立 NSIS 安装包、免安装 ZIP、源码 ZIP 和 Python 包。安装包不内置模型，冻结版未包含可选 RapidOCR；如需 OCR 可使用安装了额外依赖的源码/CLI 环境。GitHub 没有公开推送或 Release；第三方 FFmpeg GPLv3+ 的公开分发对应源码要求见 [RELEASING.md](RELEASING.md)。
